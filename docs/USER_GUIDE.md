# PopBat 使用說明

Copyright © 2026 DennisL2045

適用 Windows 10 2004 以上／Windows 11 x64。此分享版已包含 .NET 執行環境，不需另裝 .NET 或 Python。

1. 完整解壓縮 ZIP 到自己可寫入的資料夾，例如文件或桌面下的 PopBat 資料夾。
2. 執行 PopBat.exe。啟動時讀取一次；之後按「立即更新」取得新電量。
3. 查詢可能需要幾秒，已完成的裝置會先顯示。可按「取消更新」停止本輪。
4. 視窗右上角按鈕會隱藏到通知區。要完全退出，選「結束程式」。

設定區只有「啟用低電量通知」與「清除紀錄」。通知預設關閉，只在更新時判斷。電量不高於 20%、確認未充電且已有有效回覆時才可能通知；充電狀態未知時不通知。常駐期間不自動查詢，畫面顯示上次的讀取結果。

程式只讀取已連線裝置的支援電量介面，不要求管理員權限。不同品牌／韌體支援程度不同，未知電量或型號不會憑空推算。部分鍵盤的 2.4G 接收器可能只提供電量，無法提供可驗證的鍵盤型號。

支援 Fast Pair 通用電量介面的藍牙耳機，可直接取得各元件的回報。單耳時只採啟用中的耳朵，雙耳時顯示兩耳較低值；無法確認啟用狀態就不合併成單一百分比。耳機名稱可能來自目前藍牙連線資訊，畫面會註明。充電盒未提供有效值時顯示未知；耳機暫不提供續航估算。

第一次執行後可能產生 data 資料夾，儲存本機通知偏好及可用的 ROG 電量歷史；一般裝置的歷史只留在記憶體。重新分享時請使用原始 ZIP，避免把自己的 data 資料夾一起傳出去。
