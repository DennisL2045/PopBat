# 發佈前隱私檢查

2026-10-22，版本 0.4.5。

檢查應用程式原始碼、設定、開發腳本、說明、既有診斷及本機應用資料，並檢查編譯後的應用程式組件與執行檔可見字串。初次共檢查 136 個文字檔；未發現符合檢查規則的 API key、存取權杖、密碼、私鑰、實際裝置序號或藍牙位址。公開的 VID/PID、GATT UUID、協定常數與人工測試資料不是裝置序號。

發現一份舊遷移研究腳本含有三處本機使用者路徑，已改為執行時傳入參數。整個 research 目錄也排除於 Git 和分享包。GitHub 僅使用明確列出的開發檔案；GitHub 儲存庫不包含本機開發對話指示、歷史工作筆記、實機紀錄、截圖、電量資料、設定、建置快取、舊交接壓縮檔或第三方研究程式。Git 提交使用 GitHub 的 noreply 位址。

分享 ZIP 僅含 PopBat.exe、README.txt、LICENSE.txt、THIRD-PARTY-NOTICES.txt、SHA256SUMS.txt；採固定清單，不複製整個 app 目錄。封裝後重新檢查 ZIP 檔名、每個檔案的 SHA256 與編譯組件，並執行無硬體自動測試。所需的 .NET 執行環境包含在執行檔內。

應用程式沒有登入、雲端 API、付費服務、遙測或回連伺服器功能；程式自身不向作者或第三方上傳資料。偏好檔只存通知／ROG 歷史開關；電量歷史只存時間、百分比、充電旗標及本機工作階段，均不納入分享。裝置關聯識別只存在記憶體，不序列化至磁碟。Windows／.NET 自身的系統錯誤回報依系統設定運作，不屬於 PopBat 自行維運的服務。

自動規則只會回報檔名與類別，不輸出匹配到的值。第三方套件與建置快取不等於應用程式本身，也不納入上傳。這是靜態檢查及人工審查，無法保證識別所有格式的機密，不等於完整安全稽核或防外掛認證。

原始碼採 MIT 授權公開。只提供執行檔仍無法保證防止 .NET 反編譯；本次沒有加入混淆器、加殼或防偵錯工具。

## 0.4.6 本機修改檢查

新增Classic Fast Pair電量來源，不新增雲端、SDK、帳戶、API key或付費服務。只使用固定藍牙服務、電量更新與唯讀啟用元件GET；其他訊息內容直接丟棄，不記錄位址、序號或原始封包。研究工具與實機結果仍排除於Git和分享ZIP。新增連線名稱來源註明；名稱來自目前連線資訊，並非雲端型號對照。

本版檢查範圍含45個發佈文字檔與編譯後的第一方組件；模式檢查另搭配人工檢視。公開前再次檢查與授權修正見 OPEN_SOURCE_REVIEW.md。

## 0.4.8 本機相容性修正

通用 provider 保留；USB/HID 與藍牙分組，沒有新增網際網路、輸入事件、音訊、原始封包或識別資訊記錄。通用診斷包含目前裝置名稱／公開 VID/PID／電池能力／狀態、provider 階段與時間，以及 Windows、runtime、SDK 版本；不輸出持久化關聯鍵、MAC、序號、原生路徑或例外文字。SDK/runtime 列表的原始路徑只在記憶體解析，報告只保留版本。報告由使用者自行帶回，不自動傳送。

分享 ZIP 另含 Diagnose-Compatibility.ps1 與 Run-Diagnostics.cmd，固定清單增為 7 個檔案；不含診斷結果、data、原始碼快取或 HaloBattery 參考副本。
## 0.4.8 公開發佈前複查（2026-10-23）

發佈使用 Git 明確追蹤及選定的新原始碼／說明／測試腳本；不加入本機 AGENTS、歷史進度筆記、data、診斷 JSON、快取、研究用第三方儲存庫或舊壓縮檔。編譯使用 PathMap，不嵌入本機使用者來源路徑；Git 提交使用公開 noreply 身分。

複查範圍包括這次發佈檔案、可讀的儲存庫歷史、第一方編譯組件及分享 ZIP。掃描 API key、服務權杖、私鑰、密碼字面值、含憑證網址、個人路徑、序號與位址等模式，只顯示命中的檔名／類別，不輸出值。確認 ZIP 固定 7 個檔案且與 SHA256 清單一致，並在無外部 runtime 設定下執行自動測試。模式掃描搭配人工檢視，不宣稱能識別所有未知格式的機密。
