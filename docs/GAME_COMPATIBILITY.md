# PopBat 0.4.4：資源與遊戲相容性

目前沒有 Apex、Valorant、戰地風雲、英雄聯盟或 G HUB／Options+ 共存實測，沒有第三方防外掛認證或零誤判保證。程式不接觸遊戲或防外掛程序。

## 程式行為

一般使用者 asInvoker、uiAccess=false；無自動升權、服務、驅動或開機啟動。無程序注入、其他程序記憶體存取、遊戲搜尋、鍵鼠掛鉤、模擬輸入、巨集或遊戲內疊加畫面。應用程式沒有網際網路、遙測或自動更新，通知預設關閉。

BLE 只向已連線且配對的裝置直接讀標準名稱／型號／電量。沒有廣播掃描、配對、GATT 寫入或強制維持連線；不讀 Windows 電量。0.4.3 可短暫接收現有已啟用的標準 BAS 電池更新：僅讀 CCCD、不啟用或修改通知，完成即移除本機事件處理器。標準 HID 只看最少能力描述元，只有完整 battery-only Feature 才 GET_FEATURE，不讀鍵鼠輸入。USB 傳輸沿最大 8 層祖先檢查 EnumeratorName，先遇 Bluetooth 就拒絕，不能因藍牙無線電使用 USB 而放行藍牙節點。

專用控制集合只用固定電量／身份 GET：ROG 0/7/8、HID++ 白名單，以及 legacy keyboard 20/01。新增鍵盤只允許已確認 USB 05AC:024F、2.4G Dongle、MI_03、FF60:0061、report 0、相符 33/65-byte 控制集合，不讀任何鍵盤輸入集合。沒有按鍵、配對、燈效、DPI、巨集或韌體設定。

廠商安裝包、DeviceDriver.exe 和研究工具未放進程式或交接白名單。廠商軟體只離線解包與靜態分析，沒有執行。研究檔案留在 .build/research，不由 PopBat 載入。

## 資源限制

- 僅啟動一次與手動更新觸發查詢；沒有輪詢計時器或手動冷卻。只執行一輪、可取消，重新顯示視窗不觸發查詢，閒置不保留電池事件。
- 裝置 I/O 位於背景工作，部分完成就顯示；卡片保留實例，只更新資料綁定。資料仍按來源與本輪時間驗證，不為加速而讀輸入／舊電量。
- BLE 每輪最多 4 個候選、8 秒 UI 預算；識別最多快取 5 分鐘，被動電池觀察最多 6 秒、只採本輪收到的新值、不跨輪保存。
- 標準 HID 最多 512 個介面／128 個集合／32 個實體描述元、8 次安全 Feature GET、2 秒 UI 預算。
- 鍵盤後備最多 4 個實體、每筆 750ms／最多 8 個回覆、每輪 3 秒。失敗 1／2／4／8 分鐘退避；已成功的標準來源不重複查詢。
- 每種可能無法立即取消的讀取器最多保留一輪，暫緩專用 I/O、不累積工作、不採晚到舊值。取消後等底層讀取完成才釋放其資源。
- HID++ 每筆 650ms、最多忽略 32 個無關回覆、每輪 12 秒，接收器最多 6 個槽位，失敗退避。
- 最多顯示 64 筆裝置，一般歷史只在記憶體，每隻最多 7 天／2048 筆；ROG 可選歷史與偏好只在 app/data。

## 電量來源的可信程度

M75Pro 標準 BLE Read 固定回覆 94%，仍拒用此來源任何百分比。0.4.3 改接收同一標準特徵的新電池更新：Python 五次 28%，使用者確認相符；最終 C# 為 25%。不參考預期數字進行校正，沒有新通知就維持未知。此改動未啟用或修改裝置通知。

M75Pro 真正的 2.4G 路由已由使用者確認：拔掉接收器停止輸入、插回恢復。既有固定 GET 20/01 兩次取得相符回覆 16%，使用者確認與鍵盤螢幕相符或只有正常小幅差異；整合畫面另直接讀得 MX Master 3S 25%。先前無回覆不能單獨判定協定不相容。沒有新增識別／初始化命令，沒有執行廠商程式。接收器回覆不提供型號，因此仍用 USB 接收器描述；BLE 錯誤來源繼續排除，未知充電狀態不估算續航、不發低電量通知。
